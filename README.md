# KingOfTheHack
Guide de lancement — King of the Hack
Ouvrez le dossier du projet dans votre éditeur (VS Code, Thonny, PyCharm...). Dans le terminal intégré (Terminal > New Terminal), tapez :
pip install pygame openpyx1
Puis ouvrez et exécuter le fichier « main.py » pour lancer le jeu.
En cas de problème
Si Python n'est pas reconnu, relancez l'installateur Python disponible sur python.org et cochez "Add Python to PATH" lors de l'installation.
